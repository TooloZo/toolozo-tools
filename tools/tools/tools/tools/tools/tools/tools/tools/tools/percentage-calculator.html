Percentage-এর সাধারণ সূত্র

কোনো সংখ্যার নির্দিষ্ট Percentage বের করার সাধারণ সূত্র হলো:

Percentage Value = (Percentage ÷ 100) × Number

আবার একটি সংখ্যা অন্য একটি সংখ্যার কত শতাংশ তা জানতে:

Percentage = (Part ÷ Total) × 100
